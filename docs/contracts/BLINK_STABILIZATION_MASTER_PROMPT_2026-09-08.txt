8. WEATHER: НИКАКОГО ПОСТОЯННОГО POLLING

==================================================
9. WEATHER И NTFY REMOTE QUEUE
==================================================

Weather НЕ ставить заранее в общий 24-hour ntfy queue.


Причина:
прогноз должен быть свежим.


Логика:


CASE A

Mac awake at briefing time.

→ fetch Open-Meteo
→ build fresh briefing
→ direct ntfy push
→ mark today's briefing sent


CASE B

Mac asleep at briefing time.

Mac wakes later.

→ detect wake
→ today's briefing not sent
→ fetch fresh forecast
→ immediately send briefing


CASE C

Fetch failed.

→ do NOT mark briefing sent
→ retry later while awake with sane interval
→ no tight retry loop


Если Internet отсутствует:

→ GUI may show Weather unavailable
→ Personal/Astronomy continue working
→ no crash.
